### 2.1 ★ TIM1 频率不是“算出 10 kHz 就已验收”

Codex 给出的迁移参考值是 `TIM1 PSC=83, ARR=99, Center Aligned, RCR=0`。在 168 MHz TIM1 内核时钟下，分频后计数节拍为 `168 MHz / (83+1)=2 MHz`。

**需核对的三种频率：**

1. **PWM 完整往返周期频率**：中心对齐计数的精确周期与 ARR 边界定义有关。不能把 `2 × (ARR+1)` 作为无条件正确公式；按 0→ARR→0 的计数区间，常用硬件关系为 `f_CNT/(2×ARR)`，此时 `ARR=99` 约为 **10.10 kHz**，而非精确 10.00 kHz。应以目标芯片参考手册及实测为准。
2. **更新事件（UEV）频率**：在中心对齐模式下，计数上/下边界可能分别产生更新事件，且受 `RCR` 等设置影响；不保证每个完整 PWM 周期只触发一次。
3. **FOC ISR 实际执行频率**：还取决于 NVIC、更新标志处理及软件分频。必须测量 GPIO 调试翻转或其他无侵入计数结果，并排除 HAL 回调额外重复调用。

- [ ] ★ 从生成的 TIM1 初始化代码核对 PSC/ARR/CMS/RCR/ARPE，并记录具体值。
- [ ] ★ 用示波器确认 PWM 基波频率、更新中断周期、FOC 调度周期分别是多少；不要混写一个“10 kHz”。

## 5. ★ 驱动板 CTRL_SD / 过流保护真实逻辑（原理图重点）

`ATK-PD6010B_V1.0原理图.pdf` 第一页 **CTRL_SD / 过流保护备注**说明：

- 板级 `CTRL_SD=0` → H 桥无效（禁止输出）；
- 板级 `CTRL_SD=1` → 允许输出，但是否真正生效仍受 `OC_OUT` 过流信号和 R70 装配状态约束；
- **焊接 R70** 可构成过流锁存保护，需要使 `CTRL_SD=0` 才能清除锁存；
- **不焊接 R70** 为随过流条件恢复的非锁存处理。

**重要区分**：厂商教程讲的 `IR2110S SD_IN=1` 关闭，是**芯片内部**信号；这里主板的 `PF10 → CTRL_SD` 是**驱动板级控制输入**，经过外围逻辑，不能据芯片内部电平直接反推 PF10 的有效极性。

- [ ] ★ 用原理图和实物确认每块 PD6010B 的 R70 是否焊接、过流控制支路有没有改版/飞线。
- [ ] ★ 单板低风险测量确认 `PF10=0` 时板级禁止、`PF10=1` 时*仅在无故障且已经完成联锁*条件下允许；绝不可单凭“PF10 高 = 使能”就在程序启动时置高。
- [ ] ★ 把 GPIO 初始化默认为**禁止态**，只允许应用状态机在完成自检、实际保护链测试后授权使能。
- [ ] ★ 验证禁能时所有实际 H/L 门极驱动不会同时导通，且过流后系统不会意外自动重新起动。
- [ ] ★ 无急停/快速关断/过流保护验收前不允许连接运动负载进行三相开关实验。

## 13. 更正记录：相对于 Codex 粘贴日志

| Codex 记录 | 本版处理 | 原因 |
|---|---|---|
| `PF10 高=不关机` | **保留但加条件** | 驱动板 CTRL_SD=1 允许输出的板级逻辑见原理图；须区别 IR2110 SD_IN 内部逻辑，并考虑过流/锁存 |
| `TIM1 PSC83 ARR99 = 10k ✓` | **改为待验证** | 精确中心对齐周期、UEV、FOC ISR 必须分别计算并实测 |
| `TIM1 Break State=Disable` | **仅允许无功率骨架调试，禁止认作安全验收** | Break 关闭并不意味着风险已消除 |
| `PB12 GPIO_Input` | **改为需确认 BKIN 设计决定** | 主板给 PB12 分配 TIM1_BKIN 功能 |
| `ADC Continuous+TIM1 CC1 trigger=同步` | **不接受为已验证事实** | 可能仅触发初始转换，连续模式随后自由运行 |
| `TIM2 1ms` | **单轴暂用，双轴必须移出** | PM2 编码器占用 TIM2 CH1/CH2 |
| `NVIC GROUP4: (1,0) 与 (1,1)` | **标注无有效子优先级差异** | GROUP4 子优先级位数为 0 |
| `FW_F4 V1.28.0 已需安装` | **要求现场核对已装版本/兼容性** | 当前粘贴日志不足以证明本机真实软件状态 |
| `CMake preset Debug` | **先 list 后使用** | 其他 STM32 工程的 preset 不能替代目标工程验证 |

**最终签署规则**：只有 A0–A4 有可复核记录，且全部 P0 安全项解决后，才能提出 A5 单轴带功率测试申请；A5 测试仍应由具备必要能力与安全设施的人员实施。任何编译成功都不能解锁电机输出。

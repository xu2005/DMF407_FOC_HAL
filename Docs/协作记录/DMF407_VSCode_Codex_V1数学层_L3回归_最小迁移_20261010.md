### 1. 任务目标与边界

在**没有 STM32 实物**的前提下，把 Legacy 控制数学逐步抽离为可独立编译、可用固定输入验证的 C 模块，并补充少量主机 L3 用例。目标是**行为等价**，不是优化算法。

- 冻结且不编辑 `Legacy/Template222_A/`（功能基线）和 `Legacy/Template222-100/`（历史对照）。
- 保持现有 6 个 BSP、`.ioc`、CubeMX 生成代码、TIM1/TIM2/TIM3/TIM4 运行配置及 PF10 默认 Low 不变。
- **不把新数学函数接入 TIM1/TIM2 ISR、main 或电机功率输出**；不引入自动使能或带功率测试。
- `POWER-STAGE ENABLE BLOCKED`，R-01、R-03、SF-02 均不得关闭。

### 2. 执行顺序

**A. 优先完成角度与速度换算（本轮必做）**

1. 只读检查 `Legacy/Template222_A/USER/angle.c` 及相关声明、全局变量和 TIM2 的调用位置；建立极简函数对应关系。
2. 抽取与硬件无关的机械角、电角度、速度计算至现有合适的 `Control/` 或 `Motor/` 目录；若目录不存在，仅建所需最小文件。底层编码器读取应从运算中分离，以**输入计数值**代替直接读 TIM3。
3. 保留原始计算的运算次序、数据类型、符号、限幅、整数差值/回绕处理，以及实测前不可调整的常数：**4000 计数/机械转、4 极对数、机械角偏移 `0.546637118`、1 ms 调用周期**。这些是审计线索，**具体公式与转型以实际 Legacy 源码为准**；不得据此自创简化公式。
4. 扩展 `tests/host/`，测试固定输入下的机械角、电角度和转速：零位、正向、反向、跨 16 位边界、连续两次采样；实际期待值须能追溯到 Legacy 实现或独立固定参考，**不得把被测新函数的输出当作自身预期值**。
5. 单独注入已知 R-01 错误计数（±65536），观察传播影响；标注 `KNOWN RISK`，不修复编码器算法，不将风险用例的“成功重现错误”称为风险通过。

**B. 其余纯数学函数（A 通过后顺序推进，避免扩大范围）**

6. 在 Legacy 中定位 **Clarke、Park、Inverse Park、PI、SVPWM** 实际函数及依赖，优先沿用已有文件组织；只抽取纯数学、可独立测的部分，不改 PI 增益、积分更新与限幅规则。
7. 每组至多选少数具有区分力的输入进行回归：零输入、一般值、正负符号、PI 连续调用及饱和边界、SVPWM 扇区/占空比边界。比较方法、浮点容差和对照来源写明；不要为了 100% PASS 修改 Legacy 数学。
8. **如某函数与全局状态/硬件中断强耦合，记录 `DEFERRED` 和具体依赖，勿为抽取它而重构全工程。** 优先交付已验证的 A，再将 B 未完成项列入下一轮。

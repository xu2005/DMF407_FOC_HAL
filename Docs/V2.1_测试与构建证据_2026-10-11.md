python scripts/v21_validate.py

| 名称 | 内容 | 结论 |
|---|---|---|
| v21_locked_aoe | 锁拒绝清AOE，旧Update恢复MOE，App拒绝坏配置 | PASS（复现+拒绝路径） |

| v21_encoder_ambiguous | App收到精确32768锁存ENCODER | PASS |
| v21_sample_age | 新Encoder/旧ADC独立验证20ms有效、21msSTALE | PASS |
| v21_app_adc_transaction | Poll失败前后Pipeline不部分覆盖 | PASS |
| v21_off_app_replay | OFF计数增长，Start0/MOE0/CCER0，无PI或CCR写 | PASS |
| v21_off_off_timeout | 无首触发时超时锁存，绝不开PWM绕过 | PASS |
| v21_off_locked_aoe | OFF拒绝旧AOE1/LOCK1 | PASS |
| v21_off_initial_moe | OFF入口清初始MOE1 | PASS |
| v21_dwt_0 | 默认enabled/count/max0 | PASS |

原有六路Start/Stop、ADC Start/Poll、SVPWM非法值、Encoder/TIM失败、早期INIT都在同一LOCK1模型下重新执行；所有fault_check分支验证故障后受检Start拒绝及后续Update。模型不模拟APB/ADC/引脚时序。

`encoder_r01`、`math_angle_r01`、`svpwm_zero` = **KNOWN_RISK**，均保留原名称/标签；成功复现旧错误不代表关闭。

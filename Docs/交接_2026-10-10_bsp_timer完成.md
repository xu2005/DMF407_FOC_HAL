## 4. 已裁决事项（不得回退；修改须经用户同意）

1. **双 Legacy 基线**：`Template222_A` = 功能行为裁决基线，`Template222-100` = 历史对照。
   均不得覆盖。两版实质差异仅 3 处（`enable_flag` 0→1、`Speed_Kp` 0.02→0.08、
   `Speed_Ki` 0.0001→0.0015），**禁止混用**。
2. **R-01 定性**（`dee4048`）：编码器 `CNT + overflow*65536` 的 ±65536 跳变是
   **Legacy 与 HAL 均存在的边界风险**（硬件回绕不受 NVIC 调度控制）。
   不得以"同抢占级"标 PASS；L4 实测前保持 `NEEDS MEASURE`。
3. **UIF 策略**（`fc320f7`）：TIM2/TIM4 **维持不清 UIF**（保持 Legacy 不对称）。
   外部分支提议的"启动前显式清 UIF"**已被否决**；如后续确需，归 V2 独立提交与验证。
4. **启动顺序**（`main.c` USER CODE 2）：`BSP_ADC_Start → BSP_Timer_Start →
   BSP_Encoder_Start → BSP_PWM_Start`，对齐 Legacy `USER/main.c:55-59`。
5. **七条迁移规则**（任务书 §1.4 + 验收框架 §8）：参数冻结 / 先映射后封装 /
   差异审计 / 改进不与等价迁移混提 / 编译≠等价 / 功率默认禁使能 / 每模块留证据。
6. **`HAL_TIM_PeriodElapsedCallback` 归属**：定义在 `BSP/bsp_timer.c`。
   `main.c` 的 USER CODE 4 与 `stm32f4xx_it.c` **必须保持不含该函数**
   （否则链接期重复定义）。

`PF10 = PM1_CTRL_SD`（驱动板使能脚）。已核实生成代码 `Core/Src/gpio.c`
`MX_GPIO_Init()` 中含：

```c
HAL_GPIO_WritePin(PM1_CTRL_SD_GPIO_Port, PM1_CTRL_SD_Pin, GPIO_PIN_SET);
```

即**上电即置高**（复刻 Legacy `time1.c` 行为），配合 A 版 `enable_flag = 1`
构成"上电闭环"。已登记 **R-03 + V2-SF-02**。两条路线：

- **A（等价优先）**：V1 照抄现状，不动 `gpio.c`；安全整改全部归 V2。
- **B（安全优先）**：V1 即改为默认禁能（有意偏离 → 需新增差异登记 + 单独提交），
  依据："冻结原有控制参数是正确的，冻结危险的实际输出状态则没有必要"。

**须由用户选定后再动代码。** 无论选哪条，`POWER-STAGE ENABLE` 保持 BLOCKED。

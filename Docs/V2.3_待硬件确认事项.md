# V2.3 待硬件确认事项

2026-10-12。V2.3 仿真通过不改变以下门禁。

- **L4 NEEDS HARDWARE**：TIM1 Update/ADC 首触发、TIM2/TIM3 编码器实际采样、六路 PWM 禁能电平、PF10 禁能电平及故障保护链仍需真实板卡测量；软件 Low/编译/Host PASS 不能替代测量。
- **L5 POWER-STAGE ENABLE BLOCKED**：真实母线/功率级、电机闭环、驱动波形、负载和双轴位置同步精度未验证；本轮不授权功率试转。
- **双轴方案未定**：需要明确 STEP/DIR 或双电机 FOC，以及 TIM1/TIM2/TIM4、GPIO、第二轴驱动、ADC 触发/电流采样与编码器资源分配。当前 FOC 仍是一份已迁移数学/控制链，没有验证两轴各自完整三相采样/PWM。
- **时间未标定**：virtual_ticks 累加旧 period，不直接等价微秒。实际 TIM4 PSC/ARR、真实脉冲发生/同步方式和示波器测量未确认；显示 tick_hz 不能证明实际转速、实时性或同步精度。
- **输出端口尚为同步软件接收契约**：一个事件为单轴一步；未来 STEP/DIR 需定义方向建立时间/脉冲宽度及接收契约，FOC 需定义步数到位置/速度目标及异步执行/反馈契约。本轮无 GPIO/PWM/ARR/CCR 写入路径。
- **反馈为演示参数**：每步计数比、量化、偏置和按命令样本滞后没有真实传感器/机械测参；不是 TIM3 真实读数，也不是 PMSM/FOC 高保真模型。
- **既有风险保留**：encoder_r01、math_angle_r01、svpwm_zero 标记 KNOWN_RISK；不因新仿真通过而关闭。

默认 CONTROL=OFF、PF10 Low、BDTR AOE=0/LOCK=1、故障锁存及原安全路径未修改。硬件事项需另行确定设计与试验条件。
